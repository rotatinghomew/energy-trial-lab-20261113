# 记录口径

归档终端实验台的测量记录，检查仪器基线并汇总各运行配置的观测。

duration_ms 是本次观测的墙钟时间，power_mw 为平均功率；能量单位 mJ，功率乘毫秒需除以 1000。baseline 的 se_mw 描述同一批次共享的校正不确定性。completed 是结局，deadline_ms 是未完成测量的停止点，不是完成时延。

数据字段采用稳定的英文标识符。编号是业务身份，不由输入数组中的位置决定。未到达的结果与已经观察到的否定结果是不同事实。货币、时间和统计单位应按字段约定解释，不在读取时默默变换。

当前命令的输出只解释当前公开计算，不承诺示例覆盖全部业务情形。批量重放应使用新的输出位置，避免人工查看上一次运行留下的文件。

## 取消与超时的时延口径

未完成的记录保留了 `duration_ms`，但都尚未到达 `deadline_ms`，且归档没有区分“外部取消”和“超时”。因此：

- 完成概率的分母包含这些记录，未完成按失败计数。
- 能耗分母同样包含它们；它们的观测能耗是“到停止点为止”的实际能耗，不是完成所需能耗。
- 时延使用右删失的 RMST：停止点之前计入生存面积，停止点之后删失；不使用 `deadline_ms` 补齐，也不把停止点当作完成时延。
- 三条指标使用同一批重抽样样本，因此“没完成”不会让该记录从某个指标里消失。

`accounting.censored_attempts` 逐条列出这些记录及其 `stop_at_ms`、是否到达截止点、进入哪些指标和口径说明，便于复查。

## 共同支持与缺测

跨配置比较只使用 `(device_id, task, batch_id)` 区组内所有分析配置都出现过的记录。缺测区组不补造、不按负载筛选，原样列入 `comparability.tasks.*.excluded_blocks` 与 `comparability.missing_pairings`。

演练数据中，`summary` 只有 cool 批次存在全配置共同区组；warm 批次缺 `compact`/`cloud` 的配对。这是当前最关键的不可比关系：`summary` 的跨配置结论不能外推到 warm，也无法区分批次效应与配置交互。

## 空载校正的不确定性

`baseline.power_mw` 是批次共享的空载功率，`se_mw` 是其标准误。配对比较中，同一批次内两个配置使用同一个校正偏移，因此偏移会在差值中部分抵消，其剩余影响与两配置的平均时长差成正比。

输出同时给出两种不确定性：

- `net_energy_correction_range_mj`：按 ±1.96·se 对每个批次取极端的解析区间，用于逐块复查符号是否稳定。
- bootstrap 区间与联合支配概率：每次重抽样为每个批次抽取 `Normal(0, se_mw)` 的共享偏移，在同一 replicate 内传播到所有配置。

两者都不假设批次之间独立同分布；批次偏移按批次独立抽样，但同批次内共享。
